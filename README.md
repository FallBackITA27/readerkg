# readeRKG

This CLI program is meant to be a fast, accurate, reader of RKG files, meant to quickly generate and get data from MKW's RKG Files.

This is built off of the back of [Skylar's rkg-utils](https://github.com/skylarc2006/rkg-utils), I highly suggest you check out vieweRKG to get roughly a graphical equivalent of this program.

# Features
- Reads RKG Files supported by [rkg-utils](https://github.com/skylarc2006/rkg-utils)

# Usage
note: there is no `man` page or `-h` flag in the program, so this is the only documentation for the commands (unless you! want to contribute)

|flag|parameters|description|
|-|-|-|
| -f | <path> | path to the rkg file to read |
| -v |  | prints verbose data |
